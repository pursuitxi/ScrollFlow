# ScrollFlow

> 把网页变成会阅读的 GIF。

ScrollFlow 是一个用于将网页自动录制为滚动 GIF 的本地工具。  
你只需要输入网页地址，它就会自动打开页面、等待资源加载完成、触发懒加载内容、从顶部平滑滚动到底部，并最终导出一个适合展示、分享和演示的 GIF。

它特别适合用于：

- 项目主页展示
- 产品功能演示
- 论文主页展示
- GitHub README 动图
- 网页作品集展示
- 长网页内容预览
- 发布页和活动页快速演示

---

## 功能特点

### 自动滚动录制

输入网页地址后，ScrollFlow 会自动打开网页，并从页面顶部平滑滚动到底部。

### 等待网页完整加载

正式录制之前，ScrollFlow 不会立即截图，而是先等待：

- 页面加载完成
- 网络请求基本稳定
- 网页字体加载完成
- 图片加载与解码完成
- 页面高度趋于稳定

从而尽量避免把页面加载过程录进 GIF。

### 自动触发懒加载内容

很多网页只有滚动到对应区域后才会加载图片或组件。

ScrollFlow 会在正式录制前先进行一次快速预滚动，触发页面中的懒加载内容，然后返回顶部，再开始正式录制。

### 基于真实浏览器录制

ScrollFlow 使用 Playwright 驱动 Chromium 浏览器，因此不是简单地抓取网页源代码，而是真正以浏览器方式打开和渲染网页。

### 可调节录制参数

可以调整：

- 浏览器视口宽度
- 浏览器视口高度
- GIF 输出宽度
- 帧率
- 滚动速度
- 页面顶部停留时间
- 页面底部停留时间
- 最长滚动时间

### 本地运行

整个工具运行在本地电脑上。

输入的网址会由本机 Chromium 浏览器打开并录制，生成的 GIF 也保存在本地，不需要上传网页内容到第三方服务。

## 工作流程

ScrollFlow 的完整处理流程如下：

```text
输入网页地址
      ↓
启动 Chromium
      ↓
等待页面加载完成
      ↓
等待网络基本稳定
      ↓
等待字体加载
      ↓
预滚动整页
      ↓
触发懒加载内容
      ↓
等待图片解码完成
      ↓
等待页面高度稳定
      ↓
回到网页顶部
      ↓
开始正式录制
      ↓
平滑滚动到网页底部
      ↓
逐帧截图
      ↓
生成 GIF
```

只有完成前面的页面准备阶段后，ScrollFlow 才会真正开始录制。

## 参数说明

| 参数 | 说明 |
|---|---|
| 浏览器宽度 | Chromium 浏览器录制时的视口宽度 |
| 浏览器高度 | Chromium 浏览器录制时的视口高度 |
| GIF 宽度 | 最终导出的 GIF 宽度 |
| 帧率 | 每秒生成的 GIF 帧数 |
| 滚动速度 | 网页向下滚动的速度 |
| 顶部停留 | 正式滚动前在页面顶部停留的时间 |
| 底部停留 | 到达页面底部后停留的时间 |
| 最长滚动时间 | 防止超长页面或无限页面持续录制 |

默认参数已经针对常见网页展示进行了配置，通常无需修改。

## 为什么不是纯前端实现

理论上可以用一个纯 HTML 页面做简单网页预览，但浏览器安全机制会阻止它可靠地录制任意第三方网页。

常见限制包括：

- 跨域限制
- 同源策略
- `X-Frame-Options`
- `Content-Security-Policy`
- iframe 限制
- 无法直接截取其他域名页面内容

因此 ScrollFlow 使用：

```text
网页界面
+
Python
+
Playwright
+
Chromium
```

这种方式可以让工具真正打开目标网页，并以正常浏览器渲染结果进行录制。

## 页面加载策略

相比直接等待几秒后开始录制，ScrollFlow 使用了更完整的页面准备过程。

主要包括以下步骤：

### 页面加载完成

等待浏览器触发页面加载完成状态。

### 网络稳定

等待页面中的主要网络请求结束。

### 字体加载

等待网页字体加载完成，减少字体切换造成的页面跳动。

### 预滚动

在正式录制前快速滚动整页，用于触发：

- 图片懒加载
- 延迟组件加载
- 滚动触发内容
- 下方资源请求

### 图片解码

等待已经加载的图片完成解码。

### 页面高度稳定检测

连续检测页面高度。

当网页高度在一段时间内基本不再变化后，才认为页面已经准备完成。

### 返回顶部

完成所有预加载步骤后自动回到网页顶部。

此时才开始正式录制。

## 当前限制

ScrollFlow 主要面向普通公开网页。

以下类型的网站可能无法得到理想结果：

### 需要登录的网站

如果网页必须登录后才能访问，默认 Chromium 会以新的浏览器环境打开，因此无法自动继承你日常浏览器中的登录状态。

### 验证码和反爬机制

部分网站可能检测自动化浏览器，并要求：

- 验证码
- 人机验证
- 登录
- 额外安全验证

### 无限滚动页面

对于社交媒体、信息流等无限加载页面，网页可能不存在真正的“底部”。

ScrollFlow 会通过最长滚动时间避免无限录制。

### 强交互网页

某些页面只有在：

- 点击
- 悬停
- 打开菜单
- 切换标签

之后才会显示完整内容。

当前版本主要模拟网页自动向下浏览，不会主动执行复杂交互。

### 视频和动画内容

GIF 本身存在：

- 色彩数量限制
- 文件体积较大
- 帧率有限

因此包含大量高清视频或复杂动画的网页，最终效果可能不如视频格式。

## 隐私说明

ScrollFlow 默认运行在本地。

它不会主动：

- 上传你的网页截图
- 上传生成的 GIF
- 保存访问历史到外部服务器
- 将录制内容发送给第三方服务

需要注意的是，当 ScrollFlow 打开目标网页时，目标网站本身仍然会正常接收到浏览器访问请求，这与普通浏览器访问网页类似。

---

## 安全说明

建议只录制你有权访问和展示的网页。

请不要使用本工具：

- 绕过网站访问控制
- 获取未经授权的内容
- 录制包含敏感信息的私人页面
- 违反目标网站的使用条款
